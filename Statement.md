Project Statement

Project Title

Cricket Player Record and Statistics System

Problem Statement

Cricket players have different performances in different matches. Calculating a player's overall statistics manually can be time-consuming and may result in calculation errors.

The Cricket Player Record and Statistics System is developed to provide a simple way to calculate important cricket statistics using Python. The system takes player information and match-wise performance as input and calculates batting, bowling, and overall performance statistics.

---

Project Scope

The project focuses on calculating and displaying basic statistics of a cricket player.

The system includes:

- Player information
- Team and role information
- Match-wise runs
- Balls faced
- Wickets taken
- Total runs
- Highest score
- Batting average
- Strike rate
- Number of fifties
- Number of hundreds
- Total wickets
- Best wickets in one match
- Runs per match
- Wickets per match
- Overall performance rating

The current version does not use a database or permanent storage. The information is processed during program execution.

---

Target Users

The project is intended for:

- Cricket enthusiasts
- Students learning Python
- Beginners learning programming
- Users interested in calculating basic cricket statistics

---

High-Level Features

1. Player Information

The system collects:

- Player name
- Team
- Role
- Number of matches

2. Match Data

The system collects:

- Runs scored
- Balls faced
- Wickets taken

for each match.

3. Batting Statistics

The system calculates:

- Total runs
- Highest score
- Batting average
- Strike rate
- Fifties
- Hundreds

4. Bowling Statistics

The system calculates:

- Total wickets
- Best wickets in one match

5. Performance Analysis

The system calculates runs per match and wickets per match and uses them to classify the player's performance as:

- Excellent
- Good
- Needs Improvement

6. Final Report

The system displays all player information and calculated statistics in an organized format.

---

Technology Used

The project is developed using Python and uses basic programming concepts including:

- Variables
- Input and output
- Arithmetic operations
- "for" loops
- Conditional statements

No external libraries or database systems are required.

---

Expected Outcome

The expected outcome of the project is a simple Python-based system that can accept cricket player performance data and generate a useful statistical report.

The project demonstrates how programming can be used to automate calculations and analyze real-world sports data.
