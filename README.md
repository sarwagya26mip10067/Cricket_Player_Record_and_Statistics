# Cricket_Player_Record_and_Statistics

1. Project Overview

The Cricket Player Record and Statistics System is a basic Python project developed to calculate and analyze the performance of a cricket player.

The program collects player information and match-wise performance data such as runs scored, balls faced, and wickets taken. It processes this information and generates a final report containing important batting and bowling statistics.

The project demonstrates the use of basic Python programming concepts such as variables, input/output operations, arithmetic operations, loops, and conditional statements.

---

2. Problem Statement

Calculating a cricket player's performance statistics manually for multiple matches can be time-consuming and may lead to calculation errors.

This project provides a simple Python-based solution that automatically calculates important player statistics from match-wise performance data.

---

3. Objectives

The main objectives of this project are:

- To collect basic information about a cricket player.
- To collect match-wise batting and bowling data.
- To calculate total runs and total wickets.
- To find the highest score and best wickets in one match.
- To calculate batting average and strike rate.
- To count the number of fifties and hundreds.
- To calculate runs per match and wickets per match.
- To analyze the player's overall performance.
- To display the results in a clear player performance report.

8. Performance Analysis

The program evaluates the player's performance using runs per match and wickets per match.

The result is classified into three levels:

Excellent
Good
Needs Improvement

The conditions used in the program are:

- Excellent: Runs per match ≥ 40 and wickets per match ≥ 2
- Good: Runs per match ≥ 30 or wickets per match ≥ 1
- Needs Improvement: Otherwise

12. Limitations

The current version of the project has some limitations:

- Player records are not permanently stored.
- The program processes one player's data at a time.
- There is no database.
- The program does not provide graphical statistics.
- The current version does not compare multiple players.
